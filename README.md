## Hello, World 🖖! I'm Oscar

I build software and AI-powered tools designed to **save time and remove friction**. I started as a freelance web designer, delivered strong results, and now I'm going deeper into **software development, AI engineering and cybersecurity**.

My goal with AI is simple: make it a **powerful tool**, not just a "daily helper". I work mostly with **Rust, Python and C#**.

I'm self-taught: I learn by building, breaking things and retaking them. If something is wrong, I fix it.

> 💬 Ask me anything about **web design & development, software, AI automation, AI learning and marketing**.

| | |
|---|---|
